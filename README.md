# medical-platform
# 🩺 VisualMedRecord — 可视化病历本

> 一款基于 **3D 医学影像可视化** 与 **AI 辅助决策** 的交互式病历管理系统，让医生从“读文字”升级为“看器官”。

---

## 📌 项目简介

传统电子病历以文字和二维影像为主，信息密集且割裂。**VisualMedRecord** 通过 **2D / 3D 器官可视化** 与 **CT/MRI 分割重建**，将患者的病史以直观的空间形态呈现，并集成 **AI 医疗建议助手**，辅助医生快速掌握病情、制定诊疗方案。

---

## 🎯 核心功能

### 👤 用户登录与角色分流
- 支持两种身份登录：**我是医生** / **我是病人**
- 登录凭证：用户名 + 密码（**用户名全局唯一**）

### 🔍 医生端 — 病人检索
- 通过 **姓名 + 身份证号** 精确检索目标患者
- 进入该患者的 **身体状况可视化页面**

### 🧠 2D / 3D 可视化交互
- 提供 **2D 视图** 与 **3D 视图** 两种模式，功能等价，视觉效果不同
- 点击任意器官 → 进入该器官的 **详细病史展示页**

### 📐 器官展示页（左右分栏）

| 区域 | 内容 |
|------|------|
| **左侧 — 器官模型** | 有 CT/MRI 数据时，通过 **Segmentation** 重建该患者器官模型；无数据时自动加载 **默认三维器官模型** |
| **右侧 — 病历表** | 展示该器官的全部病史记录（时间、诊断、检查结果、治疗记录等） |

### 💬 AI 医疗建议悬浮球
- 页面右侧常驻 **悬浮可点击球体**
- 点击后唤起 AI 对话窗口，可针对当前患者 / 器官 **咨询医疗建议**

## 🛠️ 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **后端框架** | Python + FastAPI | 高性能异步 API 框架，自动生成 OpenAPI 文档 |
| **后端服务器** | Uvicorn | 轻量级 ASGI 服务器 |
| **数据库** | PostgreSQL | 关系型数据库，存储用户、病历、器官病史 |
| **数据库驱动** | SQLAlchemy + asyncpg | 异步 ORM，支持 Alembic 迁移 |
| **前端框架** | Vue 3 + TypeScript | 组合式 API + 类型安全 |
| **包管理** | pnpm | 快速、节省磁盘空间 |
| **状态管理** | Pinia | Vue 3 官方推荐状态管理库 |
| **构建工具** | Vite | 极速冷启动 + HMR |
| **3D 可视化** | Three.js / VTK.js | 器官模型渲染与分割重建展示 |
| **医学影像处理** | MONAI + PyTorch | 分割模型推理，Nibabel / ITK 文件读写 |
| **反向代理 / Web 服务器** | Nginx | 静态资源托管 + API 请求转发 |
| **容器化与部署** | Docker + Docker Compose | 跨平台一键启动，环境一致 |
